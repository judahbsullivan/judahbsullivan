### Judah Sullivan

I'm a software engineer and the founder of **Zenith**.

### What I'm Building
**Zenith** is an open source compiler-first UI framework designed for deterministic output, explicit contracts, and minimal runtime behavior. It's built for serious engineering teams looking for a stable and predictable UI foundation.
